# Gagan Finance Desk

Finance management application deployed on Hugging Face Spaces with PostgreSQL cloud database.

## Setup

### Environment Variables
Add this in Space Settings → Environment Variables:

- `DATABASE_URL`: Your Neon.tech PostgreSQL connection string

## Features
- Generate Invoices (PDF)
- Manage Customer Records
- Dashboard with Charts
- Settings & Configuration
- Works on PC & Mobile (Android Chrome)
